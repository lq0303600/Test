# 教师智慧校园系统

## 项目概述

**教师智慧校园系统**是一款面向大学教师的综合管理平台，旨在帮助教师高效管理教学事务、学生信息、作业考勤等日常工作。系统集成AI智能助手，提供智能问答、作业生成、自动批改等智能化功能。

## 功能模块

### 1. AI帮助中心
- DeepSeek AI智能问答
- 支持教育、技术、生活等多领域问题
- 实时显示回答时间

### 2. 个人中心
- 用户信息管理
- 账号设置（密码修改）
- 信息联动展示

### 3. 教务管理
- **我的授课**：学期选择、课程详情查看
- **课程表**：按学期查看教学安排
- **成绩录入**：按课程录入成绩
- **成绩统计**：分学科统计分析

### 4. 作业管理
- 发布作业（标题、课程、内容、截止时间）
- 结束作业
- 实时查看提交情况
- 筛选：全部作业 / 我的发布

### 5. 考勤管理
- 开始考勤（科目、日期、时间设置）
- 结束考勤
- 出勤统计
- 重点人员标记
- 筛选：全部考勤 / 我的发布

### 6. 期中测试题库
- AI出题
- 自主出题
- AI批改

### 7. 学生管理
- 学生名单查看
- 学生详情
- 人数统计

### 8. 校园服务
- **校园地图**：可视化地图、建筑物详情
- **食堂**：菜品查看、价格、位置
- **图书借阅**：检索、借阅、续借、归还
- **报修通道**：提交报修、查看修理员信息

### 9. 作业练习
- AI生成作业
- AI批改作业

### 10. 消息通知
- 系统通知
- 学术通知
- 个人消息

## 运行方式

### 环境要求
- Node.js 18.x+
- MySQL 8.0+

### 启动步骤

```bash
# 1. 进入网关目录
cd backend/microservices/gateway

# 2. 安装依赖
npm install

# 3. 启动服务
npm start
```

### 访问地址
- 本地访问：http://localhost:8080
- 网络访问：http://0.0.0.0:8080
