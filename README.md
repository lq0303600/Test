# 教师智慧校园系统

基于Node.js和Express的教师智慧校园综合服务平台。

## 技术栈

- **后端**: Node.js, Express.js
- **前端**: HTML5, CSS3, JavaScript (原生)
- **数据库**: MySQL
- **AI服务**: DeepSeek API

## 功能模块

- AI帮助 - 智能问答助手
- 个人中心 - 用户信息管理
- 我的授课 - 课程管理与详情查看
- 成绩录入 - 按课程录入成绩
- 作业管理 - 发布/结束作业，查看提交情况
- 考勤管理 - 按科目/时间记录考勤
- 期中测试题库 - AI出题与批改
- 图书馆 - 图书检索与借阅
- 校园地图 - 可视化校园导航
- 食堂 - 菜品与价格查看
- 报修通道 - 报修信息管理

## 快速开始

```bash
cd backend/microservices/gateway
npm install
npm start
```

访问 http://localhost:8080

## 数据库配置

修改 `backend/config/database.js` 中的数据库连接配置。
